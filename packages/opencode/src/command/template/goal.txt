Drive the orchestrator loop until a stated goal is achieved.

The orchestrator will:
1. Write `plan.md` capturing the goal, steps, and exit criteria.
2. Spawn coder subagents to make progress.
3. Dispatch the reviewer subagent (clean context) to judge plan.md's exit criteria.
4. Iterate until the reviewer returns VERDICT: pass, or block after exhausting retries.

Usage: /goal <condition> [--plan <path>] [--priority low|normal|high]

- condition: free-text description of what success looks like (will be passed verbatim to the orchestrator as the goal)
- --plan <path>: path to a pre-existing plan.md (defaults to ./plan.md, generated by the orchestrator if missing)
- --priority: goal priority forwarded to the reviewer dispatch

Sub-commands (no condition argument):
  /goal status   - print the active goal for the current session
  /goal cancel   - cancel the active goal
  /goal clear    - alias for cancel

The goal loop is bounded by goal achievement, not by a step count. The loop ends when:
- the reviewer returns VERDICT: pass against plan.md's exit criteria (the orchestrator marks the goal achieved),
- the reviewer returns VERDICT: blocked after `banyancode_max_goal_iterations` retries (the goal is auto-blocked and surfaced),
- or the user cancels.
