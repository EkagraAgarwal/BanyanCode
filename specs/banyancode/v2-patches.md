# BanyanCode patch ledger (OpenCode v2)

BanyanCode is a soft fork of [OpenCode](https://github.com/anomalyco/opencode) v2. Every BanyanCode feature ships as an in-tree plugin under `packages/banyancode*`, so the upstream tree stays close to the release it was forked from and upstream release tags merge cleanly.

**Rule:** every change to a file that upstream owns must have a row in the ledger below. A change with no row fails CI: `.github/workflows/banyancode-ci.yml` runs `bun script/banyancode/patch-ledger.ts`, which diffs the branch against the upstream base commit and fails on any upstream-owned path that is added, modified or deleted without a matching row. Rows may use globs (for example `.github/workflows/*`).

A row stays until the patch is upstreamed (then delete it) or dropped. Prefer an upstream PR over a local patch: every merged PR shrinks the ledger.

## Categories

| Category | Meaning |
| --- | --- |
| `branding` | Names, paths, environment variables, versioning and other user-visible identity |
| `hook` | A small seam upstream does not offer yet: a call site, a schema field, a plugin registration |
| `fix` | A bug fix that has to live here until upstream accepts it |
| `ci` | Build, release and repository automation owned by BanyanCode |

## Upstream base

- **Base commit:** `4878a0e30f` — OpenCode v2.2.5 (`release: v2.2.5 (#60744)`).
- Branch `v2-base` is a direct descendant of that commit, so `git diff 4878a0e30f...HEAD` is the complete patch set.
- Merge upstream release tags weekly, then run `bun script/banyancode/patch-ledger.ts` again.
- Move the base only when rebasing `v2-base` onto a newer upstream release (update this section and the `DEFAULT_BASE` constant in `script/banyancode/patch-ledger.ts` together).

## BanyanCode-owned paths (never need a ledger row)

These globs belong to BanyanCode and are filtered out by the check before the ledger is consulted:

- `packages/banyancode*/**` — server, TUI and MCP plugin packages
- `specs/banyancode/**` — plans, parity checklist, this ledger
- `script/banyancode/**` — BanyanCode repository scripts and their tests
- `.github/workflows/banyancode-*.yml` — BanyanCode CI workflows
- `bun.lock` — regenerated by `bun install`

Anything else is upstream-owned: adding, editing or deleting it needs a row here.
